# CPAN 144 Assignment 1

Next.js app with Home, Tasks, and Practice pages.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- `/` — welcome message and greeting form (props + form submit)
- `/tasks` — task list with add / toggle / filter
- `/practice` — tip toggle, feedback form, hover effect
